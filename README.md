# 45분 LMS 강의 대본 파이프라인 — MatrAIx 저자진·검토진

교육과정 표(엑셀)를 받아 **45분짜리 온라인 강의 대본**을 강 단위로 찍어내는 도구 모음이다.
1 credit = 45분 동영상 1강으로 보고, 과목을 강으로 나누는 것부터 슬라이드·낭독·자막·발음까지 만든다.

마스터 원고는 한국어로 쓴다. 현지어 음성과 제3언어 자막은 이 원고에서 번역해 만들므로,
한국어판이 분량·구조의 기준이 된다. 다른 분야로 옮기려면 `pack/` 의 규격·말투·용어만 갈아 끼우면 된다.

## MatrAIx 를 어떻게 쓰나

대본을 한 사람이 쓰면 그 한 사람이 놓치는 것을 아무도 못 짚는다. 그래서 **쓰는 자리와 읽는 자리를 갈랐다.**

[MatrAIx Persona-1M](https://github.com/MatrAIx-ai/MatrAIx-Persona-8B) 에서 조건을 적어 두고 **20명**을 뽑는다.
조건이 `pack/persona.yaml` 에 문장으로 적혀 있고 씨앗이 고정되어 있어서,
**제3자가 같은 조건으로 같은 20명을 다시 뽑아 확인할 수 있다.**
조건을 코드에 숨기면 "그 20명은 어떻게 뽑았나" 에 답할 수 없다.

| | 인원 | 자리 | 하는 일 |
|---|---|---|---|
| **저자진** | 4 | 임상 실무 · 교육 · 연구·근거 · 국제·현지화 | 설계 → 스토리보드 → 집필. 넷이 합의한 문서 하나를 낸다 |
| **검토진** | 16 | 1년차 4 · 2·3년차 4 · 현지 SME 4 · 교육담당 4 | 초고를 읽고 의견을 낸다. 층이 갈려야 어느 장이 막히는지가 나온다 |

같은 사람 넷은 같은 것을 놓치므로, 인원을 늘리지 않고 **관점을 갈랐다.**
자리를 정하는 조건만 `must` 로 걸고 나머지는 `prefer` 로 두어 점수로 고른다 —
조건을 여럿 AND 로 걸면 조용히 0명이 뽑힌다.

**검토는 의견이고, 결론은 파일이다.** 검토진 의견은 강별 엑셀 시트에 AS IS / TO BE 로 남는다.
지적이 없는 장도 '이상무' 로 한 줄 남긴다 — 비어 있으면 안 읽은 것과 구분이 안 된다.
반영 여부와 관계없이 탈고 파일은 반드시 완결된다.

## 구조

```
패널 ─── 저자진 4 + 검토진 16 을 뽑는다. 명부 엑셀(가명·약력·선발 조건)
  │
설계 ─── 과목 하나를 LMS credit 수만큼 강으로 나눈다.
  │      강마다 제목·학습목표 3개·본문 블록·표와 그림 후보·현지화 항목
  │
강의 ─┬─ 스토리보드  장마다 화면 종류와 낭독 목표 글자수. 코너별 예산은 도구가 먼저 계산한다
      ├─ 집필        청크로 나눠 부른다. 한 번에 다 쓰게 하면 뒤로 갈수록 분량이 무너진다
      ├─ 조립        원고 HTML 하나로. 표지·마무리 낭독은 도구가 고정 형태로 만든다
      ├─ 검수        장수·글자수·분·표/그림·금칙어·문장 길이. 모델을 부르지 않는다
      ├─ 검토        검토진 16명 → 의견
      └─ 탈고        1안 반영 → 완결
```

산출은 **슬라이드 줄글형 HTML**(장마다 하단에 표 또는 SVG 필수)과 **검수표**로 전달된다.

## 원고 HTML — 세 가지 대본을 숨겨 둔다

`h3` 하나가 슬라이드 한 장이다. 화면에 보이는 것은 슬라이드 내용이고, 말할 것은 속성에 들어 있다.

| 속성 | 무엇 |
|---|---|
| `data-say` | 자막 대본 (맞춤법대로. 자막 파일의 원본) |
| `data-read` | 음성 대본 (소리 나는 대로 — "에스바", "밀리미터 수은주") |
| `data-img` | 이미지 대본 (그 장을 그림으로 만든다면 무엇을 그릴지) |

`h1` 에는 표지·마무리 낭독이 붙는다. **h1 에 보이는 글은 강 제목 하나뿐이다** —
과정·코드 같은 관리용 정보를 화면에 두면 표지 내레이션이 그것까지 읽는다(실측).

`[LOCALIZE: 종류 — 내용]` 은 현지에서 확인·교체해야 하는 자리다. 없는 조항 번호나 통계를 지어내지 않기 위한 장치다.

이 계약은 [summary-showcase](https://github.com/leedonwoo2827-ship-it/summary-showcase) 가 그대로 읽어
덱·자막·TTS·큐시트·영상으로 만든다.

## 규격 (`pack/pack.yaml`)

- 낭독 합계 15,500~17,000자 (5.5자/초) · 슬라이드 65~80장 · 본문 장당 150~300자
- 코너: 생각해보기 → 학습목표 → 학습내용 → 본문 Ⅰ~Ⅴ(블록 = 학습목표 1개, 2,500~4,000자) → 정리하기 → 퀴즈 3~5문항(낭독 없음) → 참고문헌
- 한 문장 60자 이내, 괄호 없음 — 다른 언어로 옮겨 읽을 것을 전제한다

## 돌리는 법

```
copy pack\site.sample.yaml pack\site.yaml     이 과정이 어디를 위한 것인지 채운다
run.bat                                       메뉴
```

| 단계 | 명령 |
|---|---|
| 입력 시트 | `python tools/s00_extract.py` |
| 패널 20명 | `python tools/s01_panel.py` · 약력은 `--bio` |
| 설계 | `python tools/run.py design` |
| 초고 | `python tools/run.py draft --batch 1 --workers 2` |
| 검토·탈고 | `python tools/run.py review --batch 1` |
| 현황 | `python tools/run.py catalog` |

모델 호출은 MatrAIx 검토분석엔진의 `provider.py`(Claude Code 구독, `claude -p`)를 그대로 쓴다.
API 키를 쓰지 않는다. 엔진 경로는 `MATRAIX_ENGINE` 환경변수로 바꾼다.

이미 있는 산출은 덮지 않는다 — 다시 만들려면 파일을 옮기거나 지운다. 보낸 프롬프트는 강마다 `_prompts/` 에 남는다.

## 이 저장소에 없는 것

산출물(`data/`), 원본 교육과정 자료(`_context/`), 이 과정이 어디를 위한 것인지 담은 이름들(`pack/site.yaml`),
보낸 프롬프트 원문과 실행 기록. **도구와 방식만 둔다.**
